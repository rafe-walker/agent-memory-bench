## Controls (no finding)
**Classifier corpus (part 1):** of 61 real-change cases, 48 retract correctly, including link target/title/text, reference definitions, images, autolinks, inline HTML, pipe and pipeless tables, block quotes, front-matter-ish `---` blocks, setext `=`→`-`, fenced code (body, info string, tilde fences, whitespace inside), inline-code whitespace, indented code, zero-width chars (added, removed, counted), Cyrillic homoglyph, RTL marks, CJK/Arabic word swaps, NFC↔NFD, fullwidth letters, thin space, U+2028, entities, CRLF + a real change, bare CR, change at the end of a 600-word line, task-list checkbox, list reorder/re-nest. Benign: 8/8 quiet.
**Metamorphic / property (`r2-metamorphic.mjs`, 12 seeds):** symmetry format_only(A,B) = format_only(B,A) holds on all 69 corpus pairs; 715 seeded real mutations of 10 runbook blocks (digits, letters, zero-width/bidi, homoglyphs, dropped/swapped words, inline code, link targets, punctuation, CRLF-mixed, 400-word lines; tables, quotes, lists, CJK, Hebrew) → 0 format-only. Run twice.
**Sections (`r2-sections.mjs`):** re-level that changes nesting (### → ##) retracts; re-level without nesting change quiet; closing `##` / `## Port #` quiet (correct CommonMark); indented fence retracts; `" > "` in heading text only collides for semantically equal paths (not filed). Export → import keeps block ids and lineage (pending is local by design, FORMAT §4.2).
**Lineage / pending (`r2-lineage.mjs`):** baseline note stale + `never_act`; pulse-only re-orient keeps lineage; the plain cycle with a changed shared block is caught; cross-project note gets its `derived` retraction in its own project; pending: read-current clears, format-only twin clears, reading the middle version keeps the newest change pending, own write then someone else's change is pending, section rename = `moved` and clears on re-read, re-added block after removal stays pending.
**Pulse wording:** a single pulse after a change never says proceed (3 variants); `focus=retractions` after a carried-only put says "carry the cursor" (no proceed word).
**Secrets:** column-0 PEM, `DB_PASSWORD=`, `X-Api-Key:` header, `ghp_` token refused.
**Integrity:** a `blocks.content` edit is caught by every orient focus (control).

## Observations (not filed)
- False-stale noise: source A → B → A (revert) leaves a note derived from the first A stale (`C10`; a new block id, not format-only).
