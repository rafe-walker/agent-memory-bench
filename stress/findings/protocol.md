## Observations (not filed)

- TS SDK v2 2.4.0 defaults to `versionNegotiation: legacy`; only `mode: 'auto'` or a pin reaches 2026-07-28. Python `mcp` 2.3.0 `mode="auto"` negotiates 2026-07-28 against both servers.
- `recall` and `get_system_state` are annotated `readOnlyHint: true` but record reads / cursors (that is how re-reading clears the pulse gate); Copilot code review uses read-only tools, so a review session can clear another agent's pending gate.
- `Accept: text/html` alone is served (200) on both servers.
- `/home/claude/sea-lite/dist` (gitignored local build) predates the F07 fix that npm 0.6.0 contains; anything run from that checkout's `dist` without a rebuild tests old scope code.
- The 2025-era catalog is what mcp-catalog-snap snapshots (SDK v1 client); a server whose 2026-07-28 catalog diverged would not be caught. Server `instructions` (also part of the cached prefix) are not snapshotted.

## Coverage gaps

- No live agent hosts (Claude Code, Cursor, Codex, Copilot, Hermes binaries talking to a model): configs were parsed and launched, not exercised by the host itself; Hermes has no documented config to test.
- `checkpoint_chain {push: true}` and `anchor_status {remote: true}` never called (no network to the anchor service).
- Windows / macOS clients, HTTP/2, TLS-terminating proxies in front of `serve --http`, non-loopback binds (`--host 0.0.0.0`) not run (rule: 127.0.0.1 only).
- Elicitation / `input_required` round trips were driven only as far as the server's first answer, not through each SDK's callback.
